## How to get on this list

1. Find an open accessibility issue at [AccessibilityRocks](https://lauramoney42.github.io/AccessibilityRocks/).
2. Fix it and get the pull request merged.
3. That is it. The next Monday refresh picks you up automatically.

Only merged pull requests carrying an accessibility label count. Three rules keep the ordering honest, and they exist because the first version was gamed by accident: fixes to your own repositories do not count, each owner counts at most 3 times so helping several projects beats grinding one, and repos under 50 stars are left out. Before those rules the entire top of the list was one account's two brand new repos.

Two merged pull requests also earns you GitHub's own Pull Shark achievement, which lands on your profile rather than only here.
